# Workforce Analytics 📊

An exploratory data analysis and machine learning project focused on understanding employee performance, identifying influential factors, and generating actionable workforce insights.

## 📌 Project Overview

Organizations need to understand the factors associated with employee performance to create a healthier and more productive workplace.

This project analyzes employee data to explore performance patterns, compare departments, evaluate important features, and build machine learning models to predict employee performance ratings.

## 🎯 Objectives

- Analyze performance across departments.
- Identify factors associated with employee performance.
- Compare machine learning classification models.
- Explore ways to improve employee satisfaction and productivity.
- Present insights through data analysis and visualizations.

## 🛠️ Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## 🔍 Project Workflow

1. Load and explore the employee dataset.
2. Check missing values and prepare the data.
3. Encode categorical features and scale numerical features where appropriate.
4. Analyze department-wise performance and feature relationships.
5. Train and compare classification models.
6. Evaluate model performance and identify important features.
7. Summarize findings and provide recommendations.

## 🤖 Machine Learning Models

The original project describes experiments with:

- Logistic Regression
- Support Vector Machine
- Decision Tree
- Random Forest
- Naive Bayes
- K-Nearest Neighbors
- XGBoost
- Artificial Neural Network

## 📈 Key Findings Reported in the Original Project

- Random Forest with GridSearchCV reportedly achieved 93% accuracy.
- XGBoost reportedly achieved 92.8% accuracy.
- Environment satisfaction, salary hike percentage, and years since the last promotion were identified as important factors.

*These results are reported in the original project description and should be verified by running the notebook.*

## 💡 Potential Recommendations

- Improve workplace environment and employee support.
- Review compensation and career-development opportunities.
- Encourage a healthy work-life balance.
- Provide transparent promotion pathways.
- Use model outputs as decision-support signals rather than as the sole basis for employment decisions.
